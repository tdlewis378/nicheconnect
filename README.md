# NicheConnect

Less scrolling. More connecting.

NicheConnect is an AI-assisted social engagement and relationship-building platform for creators, coaches, consultants, and online professionals.

## Current status

This repository contains the public launch landing page and GitHub Pages deployment foundation.

## Planned production stack

- GitHub Pages for the frontend
- Supabase Authentication and PostgreSQL database
- Supabase Row Level Security for private workspaces
- Supabase Edge Functions for server-side AI and billing operations
- Stripe Checkout and subscriptions
- Official social APIs only; no scraping, passwords, cookies, or unsupported automated posting

## Local preview

Open `index.html` in a browser.

## Deployment

GitHub Pages is configured through `.github/workflows/deploy.yml`.
